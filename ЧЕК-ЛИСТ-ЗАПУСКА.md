# Чек-лист перед выкладкой на сервер

Порядок такой, чтобы не пришлось возвращаться. Отмечайте по мере выполнения.

---

## 1. Обязательное. Без этого запускать нельзя

### Домен и хостинг
- [ ] Купить домен. Хорошие варианты: `nlevel66.ru`, `nlevel-ekb.ru`, `nlevel-detailing.ru`. Короткий и с цифрой региона запоминается лучше.
- [ ] Хостинг с PHP 8.1+, расширения **GD** и **fileinfo**. Подойдёт любой за 150–300 ₽/мес: Beget, Timeweb, Reg.ru.
- [ ] Подключить бесплатный SSL-сертификат (Let's Encrypt — есть у всех хостингов в один клик). Без HTTPS Яндекс понижает сайт, а браузер пишет «не защищено».
- [ ] Настроить редирект: `http://` → `https://`, и `www` → без `www` (или наоборот, главное — одинаково везде).

### Залить сайт
- [ ] Загрузить всё, **кроме** папок `docs/`, `research/`, `tools/`, `.git/`.
- [ ] Права на запись для папок `data/` и `assets/img/uploads/` (обычно 755, иногда 775).
- [ ] Открыть `/admin/` и задать логин с паролем. **Пароль длинный, не как в приложении.**
- [ ] Проверить, что `data/content.json` не открывается по прямой ссылке. Если хостинг на nginx — попросить поддержку закрыть `/data/`, `/inc/`, `/tools/`.

### Настройки в админке
- [ ] **SEO → Адрес сайта** — вписать купленный домен. Это меняет canonical, карту сайта и ссылки в соцсетях везде разом.
- [ ] **Документы → Реквизиты** — проверить, что стоит: Пащенко Степан Александрович, самозанятый, ИНН 667026566101. Добавить **электронную почту** для обращений по персональным данным — сейчас пусто, а по закону канал связи нужен.
- [ ] **Контакты** — сверить телефон, WhatsApp, Telegram, часы работы, координаты.

## 2. Юридическое. Это не про сайт, но про штрафы

- [ ] **Подать уведомление в Роскомнадзор об обработке персональных данных.** Обязательно с 2022 года, но с 30 мая 2025-го штрафы подняли: для физлиц и ИП до 50 000 ₽, для юрлиц до 300 000 ₽. Подаётся бесплатно на сайте РКН, занимает около получаса. Вы собираете имена и телефоны в приложении — значит, это про вас.
- [ ] Показать документы юристу. Тексты написаны по 152-ФЗ и ЗоЗПП, но я не заменяю юридическую проверку.
- [ ] Завести почту на своём домене (`info@ваш-домен.ру`) — она нужна и для документов, и для доверия.

## 3. Поисковые системы

### Яндекс — главный для вас
- [ ] **Яндекс.Вебмастер**: добавить сайт → получить код подтверждения → вставить в админке, **SEO → Код Яндекс.Вебмастера**.
- [ ] Там же отправить `sitemap.xml` и проверить `robots.txt`.
- [ ] **Яндекс.Метрика**: создать счётчик → номер вписать в админке, **Документы → Номер счётчика**. Счётчик подключится только после согласия посетителя — так и задумано.
- [ ] В Метрике настроить цель на нажатие «Записаться» (событие `booking_submit` уже отправляется).
- [ ] **Яндекс.Бизнес**: в карточке организации указать новый сайт вместо `n-level.clients.site`.

### Google — второстепенный, но лишним не будет
- [ ] **Search Console**: добавить сайт → код в админке, **SEO → Код Google Search Console**.
- [ ] Отправить карту сайта.

### Убрать дубли — важно
- [ ] Поставить 301-редирект с `n-level.clients.site` на новый домен (или хотя бы сменить там ссылку на сайт).
- [ ] Решить, что делать с `nlevel-detailing.web.app`: это домен приложения, его лучше оставить как есть, но сам сайт с него убрать, чтобы не было двух копий.

## 4. Приложение записи

- [ ] **Firebase Console** → проект `nlevel-detailing` → Authentication → Settings → **Authorized domains** → добавить новый домен. Без этого вход по номеру телефона выдаст ошибку.
- [ ] **@BotFather** → `/setdomain` → указать новый домен. Это нужно для входа через Telegram.
- [ ] После этого в админке **Контакты → Как открывать приложение** можно переключить на «во всплывающем окне». Сейчас стоит «отдельным окном», потому что только так Telegram работает.
- [ ] Проверить оба входа на телефоне — по номеру и через Telegram.

## 5. Контент. Это даст больше, чем любая техническая настройка

- [ ] **Снять фото «до и после».** Самое слабое место сайта: в архиве почти нет результатов работ — только боксы и фасад. Нужно 10–15 снимков: кузов до и после полировки, салон до и после химчистки, машина в плёнке. Снимается телефоном за один рабочий день.
- [ ] Загрузить их в админке, **Фотографии**, с честными подписями — что реально на снимке.
- [ ] Уточнить в прайсе: **антихром 1 500 ₽** — за элемент или за комплект? Сейчас в примечании написано «за элемент», но это моё предположение. Если неверно — поправьте, иначе повторится главная жалоба рынка «назвали одну сумму, взяли вдвое».
- [ ] Уточнить цены на плёнку для внедорожников.
- [ ] Проверить, что все 20 цен актуальны.

## 7. Проверка после запуска

- [ ] Открыть сайт на своём телефоне и пройти весь путь: главная → услуга → прайс → записаться.
- [ ] Проверить, что плашка про статистику появляется один раз и больше не возвращается.
- [ ] Нажать все кнопки связи: телефон, WhatsApp, Telegram — должны открываться приложения.
- [ ] Проверить карту на странице контактов.
- [ ] Прогнать сайт через PageSpeed Insights — должно быть 90+ на мобильных.
- [ ] Через неделю заглянуть в Вебмастер: нет ли ошибок обхода.

## Что уже сделано и проверять не надо

- Мобильная вёрстка: 108 комбинаций страниц и ширин от 320 до 1920 пикселей, переполнений нет, все кнопки от 38 пикселей.
- Микроразметка: 64 блока для поисковиков — организация, услуги, цены, вопросы, рейтинг, хлебные крошки.
- `robots.txt`, `sitemap.xml`, `llms.txt` — генерируются сами, правятся в админке.
- Alt и title у всех изображений, выверены по самим снимкам.
- Кэш: повторное открытие почти мгновенное, сайт работает без связи.
- Безопасность: заголовки CSP, защита от подбора пароля, очистка загружаемых картинок, CSRF на формах.
- Резервные копии контента при каждом сохранении, откат в один клик.
- Отзывы подтягиваются с Яндекс.Карт сами — редактировать вручную не нужно.
