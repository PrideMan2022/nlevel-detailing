## Обязательные технические выводы из ядра

1. **Цены — текстом в HTML.** 40–60 % ключей во всех кластерах содержат «цена / цены / прайс / сколько стоит / недорого».
2. **Гео-разбивка по районам** для тонировки и полировки (Академический, Уралмаш, Эльмаш, Сортировка) — 100+ показов/мес.
3. **Синонимический ряд в заголовках:** антигравийная = полиуретановая = бронеплёнка = PPF; оклейка = обклеить машину плёнкой.
4. **Разговорные формы** («обклеить машину плёнкой» — 190/мес) добавить в тексты и FAQ.
5. **Отзывный интент** (`детейлинг екатеринбург отзывы` 14, `лучший детейлинг в екатеринбурге` 9) — выносить рейтинг 4.9 в title/description и в Schema AggregateRating.
6. **Минус-слова** обязательны при запуске Директа — иначе бюджет уйдёт на очки, часы, обучение и вакансии.
