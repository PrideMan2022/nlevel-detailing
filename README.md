# Сайт детейлинг-студии NLeveL, Екатеринбург

Статический сайт из 15 страниц. Собирается генератором на Node — правки вносятся в одном месте и разъезжаются по всем страницам сразу.

---

## Быстрый старт

```bash
node build/build.js
```

Пересобирает все HTML, `sitemap.xml`, `robots.txt`, `llms.txt`, `llms-full.txt` и `manifest.webmanifest`. Зависимостей нет — только Node.

Посмотреть локально:

```bash
python3 -m http.server 8899
```

Открыть http://localhost:8899

## Как поменять типовые вещи

**Цену услуги** → `build/data.js`, массив `priceGroups`. Цена подтянется на главную, в прайс, на страницу услуги, в JSON-LD и в `llms.txt`.

**Телефон, адрес, часы работы** → `build/data.js`, объект `biz`.

**Добавить отзыв** → массив `reviews`. Попадёт на главную, в раздел отзывов и в разметку `AggregateRating`.

**Добавить фото работы:**
1. Положите файл в `assets/img/gallery/` как `work-22.webp`
2. Сделайте миниатюру: `cwebp -q 72 -resize 600 0 фото.jpg -o assets/img/gallery/thumb/work-22.webp`
3. Добавьте строку в массив `gallery` в `data.js` — **alt пишите по тому, что реально на снимке**
4. `node build/build.js`

**Акцентный цвет** → `assets/css/style.css`, переменные `--accent`, `--accent-ink`, `--accent-dim`, `--accent-glow`. Сейчас красный, как в приложении записи.

**Логотип** — фирменная иконка из приложения (`app/icons/Icon-512.png`). Из неё сделаны шапка, подвал, фавиконки, иконки установки на телефон и картинка для соцсетей. Меняете иконку в приложении — перегенерируйте набор в `assets/icons/`.

## Приложение онлайн-записи

Страница `/booking/` — это ваше приложение `nlevel-detailing.web.app`, открытое прямо внутри страницы. Никуда не перекидывает: человек листает до окна, приложение подгружается само и он записывается, не уходя с сайта.

### Почему копия приложения лежит в папке `app/`

Сначала фрейм подключался напрямую к `nlevel-detailing.web.app` и оставался пустым. Разобрались: приложение на Flutter + Firebase **не поднимается в кросс-доменном фрейме** — браузер изолирует хранилище стороннего домена, и Flutter падает ещё до отрисовки. Проверено 6 августа 2026: три варианта пути (`/`, `/#/`, `/index.html`) — везде пусто, а та же сборка с того же домена рисуется нормально.

Поэтому сборка приложения скопирована в `app/` и открывается с того же домена, что и сайт. Из копии исключены установочные APK (156 МБ) — их по-прежнему раздаёт Firebase.

**Обновить копию после пересборки приложения:**

```bash
./sync-app.sh && node build/build.js
```

### ⚠️ Что нужно сделать, чтобы заработал вход

Приложение открывается, но авторизация проверяет домен. Домен сайта нужно один раз разрешить — иначе вход по номеру вернёт ошибку `auth/unauthorized-domain`:

1. **Firebase Console** → проект `nlevel-detailing` → Authentication → Settings → Authorized domains → добавить домен сайта (сейчас `prideman2022.github.io`, потом — ваш боевой домен).
2. **@BotFather** в Telegram → `/setdomain` → выбрать бота → указать тот же домен. Это для кнопки «Войти через Telegram».

Оба шага делаются в ваших аккаунтах — со стороны кода тут сделать нечего. При переезде на купленный домен их нужно повторить для него.

## SEO: что уже сделано

- **Мета** на каждой странице: уникальные title, description, keywords, canonical, robots, Open Graph, Twitter Card, гео-мета (`geo.region`, `geo.position`, `ICBM`).
- **Микроразметка**, 64 блока JSON-LD: `AutoRepair` (с адресом, координатами, графиком, рейтингом 4.8 и соцсетями), `WebSite`, `BreadcrumbList`, `Service` на каждой услуге, `OfferCatalog` на прайсе, `FAQPage`, `Product` + `Review` на отзывах, `ImageGallery`, `ReserveAction` на записи.
- **robots.txt**: разрешены ИИ-краулеры (GPTBot, ClaudeBot, PerplexityBot, OAI-SearchBot, Google-Extended, Applebot), закрыты AhrefsBot / SemrushBot / MJ12bot / DataForSeoBot. Прописаны `Clean-param` для UTM и `Host`.
- **sitemap.xml**: 14 URL с приоритетами, частотой обновления и картинками главной.
- **llms.txt и llms-full.txt** — для ИИ-ассистентов: факты о студии, полный прайс, описания услуг, FAQ, отзывы, маршрут.
- **Alt и title на всех 96 изображениях**, подписи выверены по самим фотографиям.
- **Скорость**: все картинки в WebP, ленивая загрузка, `fetchpriority` на первом экране, карта грузится по клику, приложение — при прокрутке до него, ноль внешних запросов при загрузке, версионирование CSS/JS по хэшу.

## Что стоит сделать дальше

1. **Купить домен и переехать** с `n-level.clients.site`. Конструктор на чужом хосте не наращивает траст — это главный тормоз в продвижении.
2. **Поставить 301** с `n-level.clients.site` и `nlevel-detailing.web.app` на новый домен, чтобы не распылять сигналы.
3. **Снять фото «до/после».** В архиве Яндекса почти нет результатов работ — только боксы и фасад. Это самый слабый пункт сайта, и чинится он камерой телефона.
4. **Уточнить объём в двух позициях прайса:** антихром 1 500 ₽ (за элемент или за комплект) и цены на плёнку для внедорожников. Иначе воспроизведём главную боль рынка — «назвали одну сумму, взяли вдвое».
5. **Подключить Яндекс.Метрику** — в `app.js` уже стоит отправка цели `booking_submit`, нужен только счётчик.
6. **Районные страницы** — ЖБИ, Уралмаш, Академический, Эльмаш. По Вордстату это 100+ показов в месяц, и у конкурентов таких страниц нет ни у кого.
7. **Блог** по темам из `docs/АНАЛИЗ-КОНКУРЕНТОВ.md`, раздел 6.3 — рынок здесь пуст.
