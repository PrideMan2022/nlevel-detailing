# Сайт детейлинг-студии NLeveL, Екатеринбург

Сайт на PHP с админкой. Весь контент — тексты, цены, фотографии, отзывы, SEO — правится через `/admin/` без программиста.

---

## Запуск на своём компьютере

```bash
php -S localhost:8080 index.php
```

Открыть http://localhost:8080 — сайт, http://localhost:8080/admin/ — админка.

При первом заходе в админку она попросит придумать логин и пароль. Они сохранятся в `data/admin.php` — этот файл никогда не попадает в репозиторий.

Нужен PHP 8.1 или новее с расширениями GD и fileinfo. На Mac ставится через `brew install php`.

---

## Как это устроено

```
data/content.json     ← ВЕСЬ КОНТЕНТ САЙТА. Один файл, никакой базы данных
index.php             ← роутер: принимает любой адрес и отдаёт нужную страницу
inc/
  config.php          настройки и пути
  data.php            чтение и запись контента, резервные копии
  auth.php            вход, сессии, защита от подбора пароля
  helpers.php         мелкие помощники шаблонов
  layout.php          каркас страницы, шапка, подвал, микроразметка
  blocks.php          повторяющиеся блоки: прайс, отзывы, карта, FAQ
  upload.php          безопасная загрузка картинок
  pages/              шаблон каждой страницы
  feeds/              sitemap.xml, robots.txt, llms.txt, манифест
admin/                админка
assets/               стили, скрипты, картинки, иконки
app/                  копия приложения онлайн-записи
docs/                 статический слепок для GitHub Pages (собирается скриптом)
research/             семантическое ядро и анализ конкурентов
```

Базы данных нет намеренно. Для сайта из 14 страниц она только усложнила бы жизнь: JSON читается мгновенно, переносится копированием и открывается любым редактором.

## Админка

Открывается по адресу `/admin/`.

| Раздел | Что правится |
|---|---|
| **Главная** | тексты первого экрана, блок обещания, карточки услуг, сравнение цен, блок «О студии» |
| **Услуги и прайс** | цены, описания, сроки, метки «чаще всего берут». Можно добавлять и удалять услуги и целые разделы |
| **Тексты страниц** | вступление и смысловые блоки каждой услуговой страницы, картинка страницы |
| **Фотографии** | загрузка, подписи (alt), категории, удаление |
| **Отзывы** | добавление, правка, удаление, блок честного разбора негатива |
| **Вопросы и преимущества** | FAQ (уходит в микроразметку для поисковиков) и шесть плашек «Почему к нам» |
| **Контакты** | адрес, телефоны, мессенджеры, часы, координаты, рейтинги на картах |
| **SEO страниц** | title, description, ключевые слова, H1 по каждой странице; домен и коды подтверждения прав |
| **Резервные копии** | откат к любой из 30 последних версий в один клик |
| **Пароль** | смена пароля администратора |

Цена, введённая один раз, сама попадает на главную, в прайс, на страницу услуги, в микроразметку для поисковиков и в файл для ИИ-ассистентов. Дублировать ничего не нужно.

### Про безопасность

- Пароль хранится хешем (`password_hash`), а не текстом.
- После 5 неудачных попыток вход блокируется на 15 минут.
- На каждой форме CSRF-токен, сессия с `httponly` и `SameSite`.
- Загруженная картинка не сохраняется как есть: тип проверяется по содержимому, а сам файл пересобирается через GD и записывается в WebP. Внутрь картинки ничего постороннего не пролезет.
- В папке загрузок выполнение скриптов запрещено на уровне `.htaccess`.
- Папки `data/`, `inc/`, `build/` закрыты от прямого обращения.
- Перед каждым сохранением делается копия — испортить контент безвозвратно нельзя.

## Публикация на хостинге

Подойдёт любой хостинг с PHP 8.1+ (от 150 ₽/месяц). Порядок:

1. Залить всё содержимое папки, **кроме** `docs/`, `research/`, `build/`, `.git/`.
2. Проверить, что корень сайта указывает на папку с `index.php`.
3. Дать права на запись папкам `data/` и `assets/img/uploads/` (обычно 755, иногда 775).
4. Открыть `/admin/` и задать логин с паролем.
5. В админке → **SEO** прописать свой домен.

Если хостинг на nginx вместо Apache, `.htaccess` не сработает — попросите поддержку настроить перенаправление всех запросов на `index.php` и закрыть папки `/data/`, `/inc/`.

## Превью на GitHub Pages

PHP на Pages не выполняется, поэтому там лежит статический слепок.

```bash
./export-static.sh
git add docs && git commit -m "Обновил превью" && git push
```

Скрипт поднимает сайт локально, обходит все страницы и сохраняет HTML в `docs/`. Шаблоны те же, что на боевом сервере, — версии не расходятся.

Превью: https://prideman2022.github.io/nlevel-detailing/

## Приложение онлайн-записи

Страница `/booking/` — приложение `nlevel-detailing.web.app`, открытое прямо внутри страницы.

Копия сборки лежит в `app/`, потому что приложение на Flutter + Firebase **не поднимается в кросс-доменном фрейме**: браузер изолирует хранилище чужого домена, и Flutter падает до отрисовки. С того же домена всё работает.

Обновить копию после пересборки приложения:

```bash
./sync-app.sh
```

Из копии исключены установочные APK (156 МБ) и папка `canvaskit` (37 МБ) — движок Flutter грузится с CDN Google, локальная копия не используется.

### Чтобы заработал вход в приложении

Домен сайта нужно один раз разрешить, иначе вход вернёт `auth/unauthorized-domain`:

1. **Firebase Console** → проект `nlevel-detailing` → Authentication → Settings → Authorized domains → добавить домен.
2. **@BotFather** → `/setdomain` → тот же домен (для входа через Telegram).

При переезде на купленный домен повторить для него.

## SEO

- Уникальные title, description, keywords, canonical, Open Graph и гео-мета на каждой странице.
- 64 блока микроразметки: `AutoRepair` с адресом, координатами, графиком и рейтингом, `Service` на каждой услуге, `OfferCatalog` на прайсе, `FAQPage`, `Product` с отзывами, `BreadcrumbList`, `ImageGallery`, `ReserveAction`.
- `robots.txt` пускает ИИ-краулеров (GPTBot, ClaudeBot, PerplexityBot, Google-Extended, Applebot) и закрывает Ahrefs, Semrush, MJ12, DataForSeo.
- `llms.txt` и `llms-full.txt` — выжимка для ИИ-ассистентов: факты, прайс, услуги, FAQ, отзывы, маршрут.
- Alt и title на всех 126 изображениях.
- Все картинки в WebP, ленивая загрузка, карта и приложение подгружаются по мере надобности.

Поисковики не дают преимущества какому-либо движку — ранжируются скорость, структура и содержание. Этот сайт быстрый именно потому, что в нём нет лишнего слоя.

## Что стоит сделать дальше

1. **Купить домен и хостинг**, залить туда PHP-версию, поставить 301 с `n-level.clients.site` и `nlevel-detailing.web.app`.
2. **Снять фото «до/после».** В архиве почти нет результатов работ — только боксы и фасад. Самое слабое место сайта, и чинится камерой телефона.
3. **Уточнить объём в прайсе:** антихром 1 500 ₽ — за элемент или за комплект; цены на плёнку для внедорожников.
4. **Подключить Яндекс.Метрику** — в `assets/js/app.js` уже стоит отправка цели `booking_submit`.
5. **Районные страницы** — ЖБИ, Уралмаш, Академический, Эльмаш. По Вордстату 100+ показов в месяц, у конкурентов таких страниц нет.
6. **Блог** по темам из `research/АНАЛИЗ-КОНКУРЕНТОВ.md`, раздел 6.3.
